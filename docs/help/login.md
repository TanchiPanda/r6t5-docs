# 登录帮助

> 🔐 R6T5 Hub 是单词闯关、积分钱包、错题本、TanchiNotes 等应用的统一账号中心。一个账号通行全部应用。

## 一、账号体系

R6T5 Hub 目前分两个节点，账号不互通：

- **🇺🇸 国际服务器（cf）**：默认节点，面向海外/国内非定向用户，使用国际区 Supabase。
- **🇨🇳 中国大陆服务器（cn）**：面向中国大陆节点的测试版，使用独立的中国区 Supabase 项目，与国际账号相互独立。

右上角 🌐 胶囊按钮可切换节点（自由浏览账号中心时）；从应用跳来时会被锁定为对应节点，避免登错。

## 二、登录方式

### 1. 邮箱密码（推荐）

1. 在登录页输入注册邮箱和密码。
2. 完成 Cloudflare Turnstile 人机验证（点一下方框）。
3. 点"登录"按钮。

第一次使用某台设备登录时，会先弹出"选择账号"卡片——如果本机缓存过账号，直接点一下就能进；没有缓存就点"+ 登录 / 添加另一个账号"输邮箱密码。

### 2. 通行密钥（Passkey）

用设备的指纹 / Face ID / PIN 或安全钥匙免密登录，更安全、也不用记密码。

- 登录页点"🔑 使用通行密钥登录"。
- 已登录后进入"🔑 通行密钥"卡片 → "创建通行密钥"绑定当前设备。
- ⚠️ **中国大陆节点暂时不开放通行密钥**（后台灰度中）。

### 3. 魔法链接（邮件免密）

输入邮箱后点"发送魔法链接"，收件箱会有一封邮件，点里面的链接直接登录。**中国大陆节点暂时关闭**该入口。

## 三、多账号切换

账号中心会把本机登过的账号缓存在浏览器里（`wordGameUsersArr`），每条记录带节点标记（🇨🇳/🇺🇸）。

- 未登录时自动弹出选择卡片，当前节点账号置顶，其他节点账号半透明并标"其他节点"。
- 已登录后：设置页点"**🔄 切换账号**"回到选择卡片，**保留**本机所有缓存账号；点"退出登录"则清除当前会话并跳回首页。
- 每条账号右侧 ✕ 只移除本机缓存，**不会**注销服务端账号。

## 四、常见问题

### Q1：提示"请先完成安全验证"，登录按钮是灰的

Cloudflare Turnstile 组件还没加载或没通过。等它转完 / 点一下方框；国内网络环境加载慢可稍等几秒。

### Q2：收不到注册 / 魔法链接邮件

- 先查垃圾邮件、推广邮件文件夹。
- 确认邮箱地址拼写无误。
- 国际节点与中国节点的账号完全独立——在 cn 注册的账号不能用 cf 节点登录，反之亦然。

### Q3：登录后数据 / 词书不见

99% 是节点错了。看页面右上角或头像下方的徽章：🇨🇳 还是 🇺🇸。从应用跳来时会自动锁节点，手动乱切会进另一个账号库。点"切换账号"重新选对应节点的账号即可。

### Q4：提示"邮箱或密码错误"

确认邮箱拼写、大小写不敏感，但密码**敏感**。同一邮箱在 cn / cf 是两条独立记录，密码可以不同。

### Q5：在其他设备上需要重新登录吗

需要。账号列表存在浏览器 localStorage 里，不跨设备同步。新设备首次登录时直接输邮箱密码即可，登录后会自动加入本机列表。

### Q6：为什么页面看起来是英文 / 提示未适配

单词闯关（中国大陆服务器测试版）是给 cn 节点用的。国际版账号（wordgm 应用）不要从 cn 入口进；右上角 🌐 切到 🇺🇸 国际服务器再试。

## 五、仍无法解决

把以下信息发给开发者：

- 你访问的完整 URL（含 `?country=cn` 或 `?country=cf`）。
- 用的设备（iOS / Android / 桌面浏览器）和浏览器。
- 报错截图。
- 邮箱（不要发密码）。
