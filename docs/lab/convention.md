# 实验室公约

> 🧪 实验室里放的是还没定型的试验性功能。用之前请先读完这一页——读完再开。

## 一、实验室是什么

Word_Funny_Game 的主体功能（学词、拼写、连连看、练习记录）都是稳定的。实验室是单独的一块地方，用来放还处于试验阶段的想法：可能好用，可能难用，也可能过几天就被删掉。

所以，实验室里的功能**不保证一直存在**，也不保证跟主体功能一样稳。

## 二、怎么开

1. **默认全部关闭。**实验室里的功能默认都是关的，页面上的入口会显示成灰色或带锁的样子。
2. **要用自己开。**到「🧪 实验室」页面，按功能下方的按钮开启；不想要了，同一个地方关掉。
3. **首次开启要先读这一页。**确认过一次之后，再开别的功能就不再拦你。

## 三、用之前请知道

| 你可能遇到 | 说明 |
|-|-|
| 界面突然变了 | 试验中的功能会边用边改，不另行通知 |
| 功能不见了 | 效果不好或方向变了就会移除 |
| 数据对不上 | 数据格式可能调整，旧记录未必能保留 |
| 手机上排版乱 | 通常先适配桌面，手机端后补 |

用试验功能导出的内容，重要的话请自己另存一份。

## 四、稳定发行

一项功能跑顺了、确认要长期保留，会转成**稳定发行**，收进实验室页面的「🗂️ 以前实验过」栏目。

稳定发行的功能：

- 常驻生效，不需要开关，也不再提供关闭；
- 跟主体功能一样对待，改动会谨慎得多。

**多选课时**是第一个转正的（2026-10-17）：在选课时页可同时勾选多个课时，再点一次取消。

## 五、你的数据

实验室功能用的是你浏览器本地的数据，跟主体功能共用同一份存档。

- 试验功能可能给自己加几个存储项，但不会去读你其他网站的数据；
- 云同步只在你自己登录账号之后才发生，同步范围跟主体功能一致；没登录就只存在本地。

## 六、反馈

试验功能就是拿来试的。**觉得哪里别扭直接说**，比闷着用有用得多——尤其是「这个按钮不知道点了会怎样」这类反馈。

## 七、其他

这份公约会随实验室的规则调整而更新。你开启功能时看到的，就是当时的版本。
