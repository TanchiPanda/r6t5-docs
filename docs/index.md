# R6T5 Hub 文档

R6T5 Hub 旗下应用（单词闯关、积分钱包、错题本、TanchiNotes）的公共文档都在这里。

## 目录

- **帮助中心** — 账号体系、登录方式、多账号切换、常见问题，见《登录帮助》。
- **法律条款** — 使用前请阅读《账户许可协议》与《隐私政策》。
- **实验室** — 试验性功能的规则与免责约定，见《实验室公约》。

## 使用说明

- 左侧目录由 `manifest.json` 驱动，点击条目切换文档。
- 右上角「在 GitHub 上编辑」可直接跳转到当前文档源码。
- 也可用 URL 参数直达某篇文档，例如：

```text
https://TanchiPanda.github.io/r6t5-docs/?path=docs/legal/terms.md
```
